O codigo do projeto esta na pasta ProjetoIntegradorWorker  a segunda pasta é apenas um backup desatualizado.

Instruçoes do projeto
instale o APK do projeto
aperte o botão de play na tela inicial
caso queira ver quais salas disponiveis, aperte o botão LOBBY para ver a lista de salas já criadas
na tela de entrada, coloque o nome de uma sala nova ou existente e aperte em PLAY
na tela de tutorial, pressione a seta para fechar o tutorial
na tela de seleção de movimento, aperte dois dos 10 botãos e pressione a seta para prosseguir
na seleção ainda, outros 5 movimentos aparecem, escolha 1, prossiga apertando a seta
por fim, escolha o movimento especial, entre os 5 botões, e aperte a seta para a tela seguinte
Na tela de seleção de fase, escolha entra duas possiveis, beco ou cidade
após a escolha, aguarde o segundo player, que fará o mesmo processo de seleção de movimentos

já na partida, o tempo é contado de acordo com a musica, os jogadores devem pressionar os botões para realizar os passos de dança
cada botão adicionara uma quantia de pontos a pontuação total, 1, 5, 5 e 10 pontos
nas duas fases presentes possuem a meta de pontuação em 200 pontos, que os jogadores devem realizar
caso o tempo acabe e não ter conseguido a pontuação necessaria, a tela de derrota ira aparecer, aperte o botão X para fechar o jogo.
se a pontuação for adquirida, a tela de vitória aparecera, pressione o botão X para fechar o jogo.
